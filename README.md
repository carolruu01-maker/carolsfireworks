# 夜空放烟花

一个基于 Web 的交互式烟花体验。支持本机单人游玩，也可通过 Node 服务开启多人协作、房间、大厅弹幕、作品编辑与 AI 创作。

相对原版，本仓库已去掉「版本教学」与「查看 Prompt」入口及相关弹窗。

## 快速开始

本机单人（无需服务端）：

```bash
# 直接双击 index.html，或用任意静态服务器打开
```

多人 / 房间 / AI 功能：

```bash
node server.js
```

然后访问 `http://localhost:5180`。局域网内把 `localhost` 换成本机 IP 即可分享给他人。

默认端口为 `5180`，也可通过环境变量覆盖：

```bash
PORT=8080 node server.js
```

## 操作

- 点击夜空：在点击位置发射烟花
- 自动演示：持续随机放烟花
- `C`：清空夜空
- `R`：随机发射一次
- 右上角 `V1`–`V8` / `V10`：切换体验版本
- 通讯面板：`http://localhost:5180/monitor.html`

## 版本一览

| 版本 | 能力 |
|------|------|
| V1 | 基础随机烟花 |
| V2 | 形状选择（随机 / 星 / 心 / 烟花 / 文字）+ 本地音效 |
| V3 | 多人同步放烟花，显示用户名 |
| V4 | 5 秒内、60 像素内的两人烟花可合并为大型烟花 |
| V5 | 带密码的私密房间 |
| V6 | 公共大厅实时弹幕（可点击回复） |
| V7 | 作品编辑、本机保存、房间内分享播放 |
| V8 | 自然语言生成烟花 / 文字 / 房间主题（需在通讯面板配置 AI） |
| V10 | 输入生日推算银河状态，用一枚烟花铺满屏幕放出 |

## AI（V8，可选）

在通讯面板的 `AI CONFIGURATION` 中配置兼容接口（如 OpenAI、DeepSeek）后即可使用。未配置或请求失败时会明确提示，不会用本地规则冒充 AI。

## 项目结构

```text
index.html / app.js / styles.css   # 主体验页
server.js                          # 多人、房间、AI 接口
monitor.html / monitor.js / .css   # 通讯可视化与 AI 配置
```

## 说明

- V1 / V2 可纯静态打开；V3 及以上请通过 `node server.js` 访问。
- V8 的自然语言图形以粒子坐标点阵绘制，可经房间同步到其他客户端。
- V10 按北半球午夜模型推算当日银河可见度与像素点阵。
