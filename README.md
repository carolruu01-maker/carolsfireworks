# 夜空放烟花

一个基于 Web 的交互式烟花体验，支持三个版本切换。

## 快速开始

直接双击 `index.html`，或用任意静态服务器打开页面。

如需本地服务（可选）：

```bash
node server.js
```

然后访问 `http://localhost:5180`。

默认端口为 `5180`，也可通过环境变量覆盖：

```bash
PORT=8080 node server.js
```

## 操作

- 点击夜空：在点击位置发射烟花
- 自动演示：持续随机放烟花
- `C`：清空夜空
- `R`：随机发射一次
- 右上角 `V1` / `V2` / `V3`：切换体验版本

## 版本一览

| 版本 | 能力 |
|------|------|
| V1 | 基础随机烟花 |
| V2 | 形状选择（随机 / 星 / 心 / 烟花 / 文字）+ 本地音效 |
| V3 | 输入生日推算银河状态，用一枚烟花铺满屏幕放出 |

## 项目结构

```text
index.html / app.js / styles.css   # 主体验页
server.js                          # 可选本地服务
monitor.html / monitor.js / .css   # 通讯可视化（可选）
```

## 说明

- V1 / V2 / V3 均可纯静态打开，无需后端。
- V3 按北半球午夜模型推算当日银河可见度与像素点阵。
